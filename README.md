# IT Automation Toolkit

A collection of practical Python automation scripts for IT support and system administration tasks.

## Features

- File organizer for common file types
- Disk usage checker
- Random password generator
- Basic system information tool
- Temporary and log file cleanup script

## Tech Stack

- Python 3

## Project Purpose

This project was built to demonstrate hands-on scripting and automation skills relevant to IT support, system administration, and entry-level cybersecurity roles.

## Scripts

### 1. File Organizer
Organizes files in a selected folder into categories such as Images, Documents, Archives, Installers, and Code.

### 2. Disk Usage Checker
Shows total, used, and free disk space.

### 3. Password Generator
Generates a secure random password.

### 4. System Info
Displays operating system, hostname, processor, architecture, and current user.

### 5. Log Cleanup
Deletes `.log` and `.tmp` files from a selected folder.
